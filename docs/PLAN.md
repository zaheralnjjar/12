# خطة بناء تطبيق «Nuevo Musulmán»

تطبيق لتسجيل المهتدين الجدد ومتابعتهم، بُني على بنية **تطبيق مناشط الدعاة**: مخطط شاشاته، وقاعدة بياناته، وطريقة صلاحياته. التعامل فيه مباشر مع جداول Google ونماذج Google.

| المرحلة | من ينفّذها | الحالة | المرجع |
|---|---|---|---|
| المرحلة الأولى (الأساس) | Claude | **منجزة** في هذا المستودع | القسم الثالث |
| المرحلة الثانية | الوكيل الخارجي، بمراجعة Claude | لم تبدأ | [`AGENT_PLAN.md`](AGENT_PLAN.md) |
| النشر | المالك | لم يبدأ | [`DEPLOY.md`](DEPLOY.md) |

## أولًا: القرارات المعتمدة في الحوار

| البند | القرار |
|---|---|
| المعمار | مثل `duat-app`: خادم Google Apps Script، وقاعدة بيانات في جدول Google، وواجهة React/TypeScript، ودخول بحساب Google |
| اللغة | التطبيق كله بالإسبانية |
| المشرف | يرى كل شيء، ويدير لوحة التحكم |
| المعلم (Maestro) | هو الشيخ الذي حضر إعلان الإسلام، وهو الطبقة الثانية. يرى المسندين إليه فقط، ويكتب المتابعة والملاحظات |
| المتعاون | موظف يسجّل فقط، ولا يرى شيئًا بعد الإرسال |
| الراغب في الإسلام | يملأ نموذج Google، أو **رابطًا شخصيًا لمرة واحدة يصله عبر WhatsApp** لمن أسلم عن بُعد، دون أن يدخل التطبيق |
| تخصيص الحقول | المشرف يحدّد لكل حقل: هل هو مستعمل، وهل هو إلزامي، وهل يظهر في الرابط الشخصي. ويضيف حقولًا خاصة بنص توضيحي، لموضوع فقهي يحتاج تبيينًا أو معلومة ثقافية مثلًا. وتُضبط مراحل التعلّم من الإعدادات أيضًا |
| المعلمون والجنسيات | قوائم تُدار من الإعدادات، و**تُعطَّل ولا تُحذف** |
| الشاهدان وختم المركز | أُلغيا، فهما غير ضروريين |
| الشهادة | رقم تسلسلي، واسم المهتدي، وتاريخ الإصدار، ومُصدِرها، ورقم الملف، وحالتها (صالحة أو ملغاة). المُصدِر هو الشيخ أو «المركز الإسلامي» بصيغة عامة، دون تسمية مركز بعينه. بالإسبانية، مع نسخة ثنائية عربية وإسبانية لمن يسافر إلى بلد عربي |
| أرقام WhatsApp | أرجنتينية وأجنبية، تُطبَّع إلى الصيغة الدولية |
| السجلات القديمة | تُدخل كلها من جدول ردود النموذج، قراءة فقط |

## ثانيًا: قاعدة البيانات (المنفَّذة)

أسماء الجداول والأعمدة مطابقة لما في `server/00_Config.js`.

| الجدول | المحتوى |
|---|---|
| `Users` | الحسابات: البريد، والدور، والمعلم المرتبط، والتفعيل، وتاريخ انتهاء صلاحية الحساب |
| `Maestros` | المشايخ: الاسم، و**الصيغ البديلة للاسم** (لاستيراد النموذج)، والهاتف، والبريد، والتوقيع، والتفعيل |
| `Conversos` | سجل المهتدي: الحقول الأساسية، و`extra` لإجابات الحقول الخاصة، و`revisar` لأسباب المراجعة، و`origen` لمصدر السجل (النموذج، أو المتعاون، أو التطبيق، أو الرابط) |
| `Seguimiento` | المتابعة: التاريخ، والنوع، والملخص، والخطوة التالية وموعدها |
| `Etapas` و`Progreso` | مراحل التعلّم القابلة للضبط، وما أنجزه كل شخص منها |
| `Nacionalidades` | قائمة الجنسيات |
| `CamposBase` و`Campos` | ضبط الحقول الأساسية، والحقول الخاصة التي يضيفها المشرف |
| `Documentos` | صور الهوية والجواز، محفوظة في Drive خاص |
| `Certificados` | الشهادات: الرقم، والبيانات المجمَّدة لحظة الإصدار، والحالة |
| `Invitaciones` | الروابط الشخصية. يُخزَّن تجزيء الرمز (hash) فقط، والرابط يُستعمل مرة واحدة وتنتهي صلاحيته |
| `Contactos` | الجهات والأشخاص من غير المهتدين |
| `FormInbox` | سجل ردود النموذج التي استُوردت، لمنع التكرار |
| `Auditoria` | فتح الوثائق، والتصدير، وإصدار الشهادات وإلغاؤها، والحذف، وإعادة الإسناد |

## خامسًا: قواعد الخصوصية (ملزمة)

- ملف الردود الحقيقي **لا يُرفع إلى المستودع ولا إلى أي خدمة خارجية**. ملفات `xlsx` و`csv` مستثناة في `.gitignore`.
- رقم الوثيقة والصور وتاريخ إعلان الإسلام:
  - لا تظهر في القوائم.
  - التصدير الكامل للمشرف وحده.
  - فتح الوثائق يُسجَّل.
- لا إرسال آلي ولا رسائل جماعية عبر WhatsApp.
- يجب إيقاف «عرض ملخص النتائج» في نموذج Google.
